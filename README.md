# React + TypeScript Practice

Small React + TypeScript projects, each focused on one common concept or pattern.

## Exercises

| Exercise | Concepts practiced | Project |
| --- | --- | --- |
| Build a searchable list | `useState`, filter | [searchable-users](searchable-users/) |
| Build an autocomplete with API suggestions | `useEffect`, fetch, debounce | [autocomplete-app](autocomplete-app/) |
| Create a reusable modal | Props, state, components | [reusable-modal](reusable-modal/) |
| Fetch users and display loading/error states | Async operations, `useEffect` | [user-list](user-list/) |
| Implement pagination | Array slicing, state | [pagination-app](pagination-app/) |
| Debug unnecessary re-renders | React rendering, memoization | [render-debug](render-debug/) |
| Create a typed reusable component | TypeScript interfaces, generics | [typed-components](typed-components/) |
| Build a services directory page with a product search | Component composition, callback props, debounced fetch | [services-directory](services-directory/) |

## Running a project

Each folder is a standalone Vite app:

```bash
cd <project-folder>
npm install
npm run dev
```
